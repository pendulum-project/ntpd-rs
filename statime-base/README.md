# statime-base

Foundational types and traits for the statime time synchronization ecosystem.
This defines fundamental time types such as timestamps and durations in a
manner easy to use in time synchronization daemons, as well as several core
identifiers and traits used across the statime ecosystem crates. This crate is
part of the [statime time daemon](https://github.com/trifectatechfoundation/statime).
